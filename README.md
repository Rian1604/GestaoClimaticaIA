# 🌱 EcoIA — Classificador de Risco de Desmatamento

O **EcoIA** é um projeto desenvolvido em **Java** com o objetivo de demonstrar como técnicas de **Inteligência Artificial** podem ser aplicadas à sustentabilidade e ao monitoramento ambiental.

O sistema utiliza o algoritmo **K-Nearest Neighbors (KNN)** para classificar o risco de desmatamento de uma determinada área com base em características ambientais.

## 🎯 Objetivo

Demonstrar, de forma prática e didática, como a Inteligência Artificial pode auxiliar na identificação de áreas com diferentes níveis de risco de desmatamento.

O projeto foi desenvolvido com foco acadêmico, permitindo estudar conceitos de:

* 🤖 Inteligência Artificial
* 🌳 Sustentabilidade
* 🌎 Monitoramento ambiental
* 📊 Classificação de dados
* ☕ Programação Java
* 🧠 Algoritmo KNN
* 🖥️ Interface gráfica com Java Swing

## 🔍 Como funciona

O sistema analisa quatro características principais:

| Característica               | Descrição                                               |
| ---------------------------- | ------------------------------------------------------- |
| 🌳 Histórico de desmatamento | Indica o nível de desmatamento registrado anteriormente |
| 🛣️ Distância até estradas   | Considera a distância da área até estradas              |
| 🌿 Área protegida            | Percentual da região que possui proteção ambiental      |
| 🔥 Focos de calor            | Quantidade de focos de calor identificados              |

Com essas informações, o algoritmo **KNN** compara os dados informados com exemplos existentes na base de treinamento e classifica a área em um nível de risco.

### Classificações

* 🟢 **Baixo risco**
* 🟡 **Médio**
